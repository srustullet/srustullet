### 🎭 Demos: "Dressing room"

Four small games about why words need labels in natural language generation. You can try them on my [portfolio](https://srustullet-portfolio.vercel.app/). They use curated examples, not live AI.

| Demo | What it shows |
|---|---|
| **Untranslatable** | "Home": English hears a place, Catalan hears a man. Pick a word and see which nuance did not survive the translation. |
| **Acoustic Essence** | A concept like "fairness" has no single meaning. Pick a concept and see which related meanings a song used. |
| **The Bias Lens** | A machine that cuts some languages into more fragments reads them with less context. One photo, five versions. |
| **The Semantic Drift** | A copy of a copy keeps the outline and loses the detail. What happens when machines learn from copies of copies. |
